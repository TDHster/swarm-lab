# Фазовый переход в стае (модель Вичека)

Vicsek, Czirók, Ben-Jacob, Cohen, Shochet. *Novel type of phase transition in a system of self-driven particles.*
Phys. Rev. Lett. 75, 1226 (1995).

Каждая частица летит со скоростью v₀; курс = средний курс соседей в радиусе 1 (включая себя) + случайный угол
из [−η/2, η/2]. Края склеены. Порядок φ = |Σ vᵢ| / (N v₀).

Устройство: `js/model.js` — модель (решётка ячеек 1×1 для поиска соседей), `js/app.js` — поле, график φ,
фазовая диаграмма (отдельный рой до 1000 частиц, 600 шагов разгона + 600 замера на точку), `tools/smoke.js` — проверки.

## Замеры (N = 1000, плотность 2, v₀ = 0,3, 1000–1500 шагов разгона, если не сказано иначе)

| Что | φ |
|---|---|
| шум 0,5 / 1 / 2 / 2,5 / 3 / 3,5 / 4 / 5 | 0,98 / 0,92 / 0,72 / 0,50 / 0,31 / 0,11 / 0,06 / 0,03 |
| шум 1, со старта «вразнобой» до φ = 0,6 | ~100 шагов |
| шум 2, плотность 0,1 / 0,25 / 0,5 / 1 / 2 / 4 / 8 | 0,04 / 0,07 / 0,17 / 0,53 / 0,71 / 0,79 / 0,82 |
| шум 2,5, v₀ = 0 / 0,03 / 0,1 / 0,3 / 1 (4000 шагов) | 0,19 / 0,40 / 0,37 / 0,53 / 0,66 |
| полный шум, N = 100 / 400 / 1600 | 0,095 / 0,048 / 0,023 (≈ 0,89/√N) |
| шум 2 / 2,5 / 3 / 3,5 / 4, N = 100 (3 seed) | 0,77 / 0,64 / 0,47 / 0,32 / 0,19 |
| то же, N = 3200 | 0,69 / 0,47 / 0,14 / 0,06 / 0,03 |
| шум 2,5 / 3 / 3,5: старт вразнобой vs все в одну сторону | 0,51 vs 0,54 / 0,27 vs 0,22 / 0,11 vs 0,11 — гистерезиса нет |

При v₀ = 0 частицы — стоящие «стрелки компаса»: поле распадается на пятна разных направлений, φ в среднем 0,2
и гуляет от 0,1 до 0,3. Движение перемешивает соседей и даёт дальний порядок (Toner & Tu 1995).
