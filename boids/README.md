# Стая (Boids)

Модель Крейга Рейнольдса (1986–87): каждая птица видит соседей в радиусе зрения и угле обзора и следует трём
правилам — разделение, выравнивание, сплочённость. Стая, вожак и строй нигде не заданы, они возникают сами.

Открыть: `index.html` (работает и с диска, и через сервер). Ползунки меняют поведение на ходу.

## Устройство
- `js/model.js` — птицы (typed arrays), сетка соседей (counting sort по клеткам размером с радиус зрения),
  три правила как рулевые силы Рейнольдса `desired·maxSpeed − v` с ограничением `maxForce`, хищник, препятствия, стены.
- `js/draw.js` — два канваса: шлейфы (затухающая заливка) и оверлей (препятствия, хищник, силы одной птицы).
- `js/app.js` — ползунки строятся из массива `SLIDERS`, пресеты, цикл с фиксированным шагом 60 раз в секунду.
- `tools/smoke.js` — `node tools/smoke.js`: модель без браузера, проверки инвариантов и эффекта правил.

## Что проверено (seed 1, 600 птиц, порядок после 20–25 с)
| Настройка | Порядок | Соседей в среднем |
|---|---|---|
| по умолчанию | 0.88 | 34.5 |
| выравнивание 0 | 0.06 | 36.7 |
| сплочённость 0 | 1.00 | 6.7 |
| радиус зрения 150 | 0.97 | 436 |
| угол обзора 60° | 0.75 | 77.8 |

Скорость: 3000 птиц — ~4.6 мс на шаг в Node на M1; в Chrome 60 FPS.
