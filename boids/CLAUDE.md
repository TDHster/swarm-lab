# boids — заметки для работы

- Модель без DOM (`js/model.js`), скрипты классические (не ES-модули) — чтобы страница открывалась с `file://`.
  В Node модули подключаются через `module.exports` в конце файла.
- Мир фиксированный 1200×700, канвас масштабирует его (`scale = canvas.width / WORLD_W`), поэтому поведение не зависит
  от размера окна. Шаг фиксированный (60/с), при тормозах лишнее время выбрасывается, а не копится.
- `MAX_VISION = 150`: сетка должна быть не уже 3 клеток, иначе при сквозных краях соседи посчитаются дважды.
- Глобальные имена в `app.js` не должны совпадать со свойствами `window` (было: `history` → `orderHistory`).
- Затухание шлейфов полупрозрачной заливкой оставляет не больше 1 уровня яркости над фоном — проверено, это не баг.
- Подсказки «Что попробовать» проверены прогоном модели (таблица в README); меняя модель, перепроверить.
- `node tools/smoke.js` — перед коммитом.
