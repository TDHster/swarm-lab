# Пробка из ниоткуда (кольцо Сугиямы)

Sugiyama et al. *Traffic jams without bottlenecks — experimental evidence for the physical mechanism of the formation
of a jam.* New J. Phys. 10 (2008): 22 машины на кольце 230 м. Stern et al. *Dissipation of stop-and-go waves via
control of autonomous vehicles: Field experiments.* Transp. Res. C 89 (2018): одна машина с автопилотом гасит волны.

Модель (`js/model.js`): люди — IDM (Treiber, Hennecke, Helbing 2000), v0 = 15 м/с, s0 = 2 м, b = 1,5 м/с², длина машины 4,5 м,
плюс белый шум ускорения (σ = «неровность») на каждом шаге 0,1 с. Автопилот: средняя своя скорость за 30 с +
догон min(2, 0,1·(зазор − 8 м)), ускорение 0,5·(цель − v), но не больше, чем у спокойного IDM (a = 1,5) — то есть не ближе безопасного.

Подбор (22 машины, T = 0,6 с, неровность 0,2; средние за 300 с после 300 с разгона):

| Что | км/ч | стоят из 22 |
|---|---|---|
| без неровности | 23,1 | 0 |
| a = 0,5 / 1 / 1,5 / 2 | 6,6 / 9,7 / 20,3 / 23,1 | 13 / 12 / 1,6 / 0 |
| 14 / 16 / 18 / 20 машин | 43 / 39 / 34 / 19 | 0 / 0 / 0 / 4 |
| T = 1,0 / 1,5 с | 9,9 / 9,5 | 9,5 / 0 |
| 1 автопилот (выбранный регулятор), a = 1 | 22,7 | 0 |
| 3 автопилота, a = 0,5 | 21,1 | 0 |

Регулятор автопилота перебирали: окно 30/60 с, зазор догона 8/20/35 м, догон до 0,5/2 м/с. Без догона (первая версия)
автопилот медленно «сползал» к скорости пробки и тормозил всё кольцо (3,6 км/ч против 6,6 без него). При a = 1 все варианты
с догоном гасят пробку; больший зазор догона — меньше итоговая скорость (35 м → 15 км/ч), выбран 8 м.

Проверки `node tools/smoke.js` (<1 с): пробка появляется через 136–169 с, устоявшаяся — 9,8 км/ч, 11 стоят; один автопилот
гасит её за 54–71 с, дальше 21,9 км/ч; идеальные водители + одно торможение 2 с — пробка навсегда (9,6 км/ч);
18 машин ровно (33,7), но от торможения пробка; 16 машин после торможения снова ровно; a = 2 — пробки нет.
