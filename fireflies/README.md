# Синхронизация: светлячки и мост Миллениум

Две страницы: `index.html` — светлячки, `bridge.html` — мост.

## Светлячки (`js/fireflies.js`)

Импульсно-связанные осцилляторы (Mirollo & Strogatz 1990; Peskin 1975). Фаза растёт с периодом ≈ 1 с (свой у каждого,
разброс ±spread); на 1 — вспышка и сброс в 0. Видящий вспышку в радиусе R: фаза += ε·фаза; дошёл до 1 — вспыхивает
в том же шаге (цепочка). Только что вспыхнувшие в этом шаге не подталкиваются. Поле 16 × 9, шаг 0,01 с.
Мера r = |среднее e^(2πi·фаза)|.

Замеры (300 светлячков, R 1,5, ε 0,03, разброс ±3%, seed 1–4; «синхр.» — время до r > 0,9; r — среднее за 160–180 с):

| Что | Результат |
|---|---|
| по умолчанию | синхр. 22 / 24 / 24 / 27 с |
| ε = 0 | r 0,04–0,06 |
| 150 / 200 / 600 светлячков | r 0,36–0,59 / синхр. 46–70 с или нет / синхр. 5–7 с |
| разброс ±10% / ±20% / ±30% | r 0,43–0,87 / 0,18–0,28 / 0,11–0,14 |
| R 1 / R 3 | r 0,11–0,77 / синхр. 1–2 с |
| «встряхнуть» круг радиуса 2 после синхронизации | r снова > 0,95 через 0,3–23 с |

Отброшено: «фонарик» (клик = вспышка, которую видят соседи). Кликами в ритме 0,8–0,9 с ближних светлячков подогнать
не удалось: доля их вспышек сразу после клика 3–11%, как случайно — синхронная стая сильнее одного фонаря.
Заменено на «встряхнуть».

## Мост (`js/bridge.js`)

Strogatz, Abrams, McRobie, Eckhardt, Ott. *Crowd synchrony on the Millennium Bridge.* Nature 438, 43–44 (2005).
M·X'' + 2ζΩM·X' + Ω²M·X = G·Σ sin θᵢ;  θᵢ' = Ωᵢ + C·A·sin(Ψ − θᵢ + α), X = A sin Ψ, α = π/2.
M = 113 000 кг, Ω = 2π·1,03 рад/с, G = 30 Н, частоты походки — нормальные, среднее 1 Гц, σ = 0,1 Гц, ζ = 4%.
Порог: N_c = 4ζΩ²M / (π G C P(Ω)) (баланс силы «попавших в такт» G·N·π·P·C·A/2 и демпфирования 2ζΩ²M·A).
**C = 80 подобрана**, чтобы N_c = 165 — около порога, найденного Arup на настоящем мосту. Первая версия формулы
теряла множитель Ω, и с C = 16 мост не раскачивался даже при 600 людях — проверяйте порог прогоном, а не формулой.

Замеры (шаг 0,005 с; «в такт» — фаза в пределах ±0,3 рад от Ψ + α, случайно ≈ 10%):

| Что | Результат |
|---|---|
| 100 человек, 300 с | раскачка 1,5 мм, в такт 9% |
| 300 человек | 1 см через 21 с, 2,2 см, в такт 59% (r ≈ 0,93) |
| 300 человек, ζ = 20% (N_c 827) | 0,07 см |
| 300 человек, σ = 0,3 Гц (N_c 477) | 0,18 см |
| +10 человек каждые 20 с, seed 1–3 | 1 см при 200 / 220 / 210 людях |

`node tools/smoke.js` (~10 с) проверяет все цифры обеих страниц.
