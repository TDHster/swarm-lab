# Стигмергия: тропинки и термиты

Две страницы: `index.html` — тропинки в парке, `termites.html` — термиты (кучи щепок; столбы и камера).

## Тропинки (Helbing, Keltsch & Molnár 1997)
Газон 180×105 клеток по 0,5 м. Удобство G: шаг вытаптывает G += I·(1−G), трава отрастает G −= G/T.
V — G, размытое тремя box-blur (≈ Гаусс радиуса σ). Направление пешехода: к цели + λ·∇V·σ; тяга к тропе
ограничена 0,9 от тяги к цели (иначе при λ ≥ 8 пешеходы навсегда застревали на тропах — проверено).
Проверено (`four`, 40 тыс. шагов): путь длиннее прямого на ~0% / 18–24% / 40% при λ 0 / 8 / 20.
Скриншотами: λ 0 — все прямые; λ 8 — стволы с развилками; λ 20 — сеть с петлями; газон с дорожками по краю:
λ 0 — диагонали, λ 3 — срез дугой, λ 8 — по дорожкам; живучесть 500 — рыхлая сеть, 20 000 — сеть с развилками.
Площадь вытоптанного почти не зависит от λ (460–560 м²) — поэтому на странице её не используем как довод.

## Термиты
- Кучи (Resnick 1994): 300 термитов, 15% щепок — кучи 627 → 97 → 41 → 22 → 19 за 100 тыс. шагов, самая большая 14 → 633; щепки сохраняются.
- Столбы (по Bonabeau et al. 1998): роняют с вероятностью s²/(s²+K²) (+0,0005), идут на запах с вероятностью follow.
  6000 шагов: 36 столбов, шаг 7,4; выветривание 5% — 56 / 5,2; расплывание 0,6 — 20 / 8,4; follow 0 — ни одного;
  с маткой — 93% глины на кольце камеры.

`node tools/smoke.js` — все эти проверки (~1 мин).
