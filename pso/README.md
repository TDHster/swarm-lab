# Рой частиц (PSO)

Метод роя частиц (Kennedy & Eberhart, 1995) ищет минимум двумерных тестовых функций: Сфера, Растригин, Экли,
Розенброк, Химмельблау, Швефель. Скорость частицы: `v ← w·v + c1·r1·(p − x) + c2·r2·(g − x)`.
Топология — весь рой (gbest) или кольцо из двух соседей (lbest).

Открыть: `index.html` (работает и с диска). Частицы плавно движутся между итерациями (скорость — ползунок).

## Устройство
- `js/model.js` — `FUNCTIONS` (функция, область, где минимумы) и `Swarm` (шаг, история лучшего значения и разброса).
- `js/draw.js` — карта высот (лог-шкала, изолинии) считается один раз на функцию; частицы, рекорды, разложение скорости частицы #0; график сходимости.
- `js/app.js` — ползунки из `SLIDERS`, пресеты, цикл.
- `tools/smoke.js` — `node tools/smoke.js` — инварианты; `--table` — таблица успеха по 60 seed (~1 мин).
