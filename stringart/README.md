# Стринг-арт: картина одной нитью

`js/stringart.js` (без DOM): картинка → «темнота» 0..1 в круге S × S (на странице S = 300), N гвоздей по кругу.
Нить пропускает (1 − плотность) света; плотность = толщина нити / (диаметр доски / S).
Выигрыш хорды = насколько уменьшится Σ(темнота − картинка)² вдоль неё. Жадный: лучшая хорда от текущего гвоздя;
стоп, когда ни одна не улучшает. Колония: 8 муравьёв × цепочки по 3 хорды (из 12 лучших по выигрышу,
вероятность ∝ τ·выигрыш⁴), кладётся первая хорда лучшей цепочки, феромон на хорды лучшей цепочки.
Ошибка для сравнения — средний квадрат разницы после размытия 3 × 3.

Замеры (S = 300, 200 гвоздей, пропуск 10, плотность 0,15 — доска 40 см, нить 0,2 мм):

| Картинка | Нитей до остановки | Ошибка | Колония |
|---|---|---|---|
| сердце | 968 | 0,321 → 0,094 | ±1,3%, в 24+ раз дольше |
| лицо | 678 | 0,105 → 0,026 | то же |
| спираль | 1010 | 0,188 → 0,033 | то же |
| солнце | 379 | 0,108 → 0,028 | то же |

Сердце при плотности 0,3 / 0,15 / 0,075: 446 / 968 / 1945 нитей.

История: первая версия считала выигрыш как «среднюю недостающую темноту» и вычитала темноту линейно — нить
клалась и тогда, когда портила картину; ошибка после ~1000 нитей росла. Точный выигрыш по ошибке дал остановку сама собой
и ошибку ниже. Колония муравьёв не помогла ни с линейным, ни с точным выигрышем (две попытки) — оставлена на странице
как честное сравнение: ранний выбор здесь мало ограничивает поздние, жадный уже почти оптимален.

`node tools/smoke.js` (~1 мин) проверяет все цифры.
