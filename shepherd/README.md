# Собака-пастух

Strömbom, Mann, Wilson, Hailes, Morton, Sumpter, King. *Solving the shepherding problem: heuristics for herding
autonomous, interacting agents.* J. R. Soc. Interface 11 (2014).

Модель (`js/model.js`), как в статье: поле 160 × 90, личное пространство r_a = 2, овца бежит со скоростью 1, собака 1,5.
Овца, заметив собаку (ближе r_s = «пугливость»): направление = 0,5·прежнее + c·(к центру k ближайших) + 2·(от слишком близких)
+ 1·(от собаки) + e·случайное; без собаки пасётся — шаг в случайную сторону с вероятностью 0,05.
Собака: все овцы в круге r_a·N^(2/3) от центра → «гнать» (точка за центром на расстоянии r_a·√N, на линии от загона),
иначе «собрать» (точка за самой дальней овцой на расстоянии r_a). Ближе 3·r_a к любой овце — почти стоит. Шум собаки 0,3.
Отличие от статьи: число соседей k задаётся долей стада (по умолчанию 50%), загон — квадрат 30 × 30 в углу,
«загнали» = все овцы внутри квадрата.

Замеры (шагов до «все в загоне», seed 1–4; «—» — не загнали за 8000 шагов):

| 10 / 100 овец | 253–395 / 460–652 |
| сплочённость 0 / 0,5 / 2 | — / 1346–3240 / 221–1143 |
| соседей 5% (3 из 50) | — |
| 100 овец, соседей 25 (25%); с 50% — 460–652 | — |
| пугливость 10 / 20 / 35 | — / 683–4080 / 250–3437 |
| скорость собаки 0,7 / 3 / 5 | 524–755 / 222–1037 / 220–418 |
| случайность 1 / 2 | 311–618 / 546–1368 |

Быстрая собака стадо не «рассыпает» (правило «не врываться» её тормозит) — такую подсказку не давать.
Первая версия считала соседей штуками (25): со 100 овцами стадо распадалось; поэтому ползунок — доля стада.

`node tools/smoke.js` (~25 с) проверяет все цифры подсказок.
