# Рой роботов собирает фигуру

По эксперименту Kilobot (Rubenstein, Cornejo & Nagpal, Science 2014). Радиус робота = 1, связь — 5,5.
Правила: градиент (BFS по стоящим), трилатерация (МНК, отказ при почти коллинеарных соседях), старт с наибольшим
градиентом среди соседей при отсутствии едущих рядом, езда вдоль края (дистанция 2,3), остановка внутри фигуры,
если следующий шаг выводит наружу или рядом стоит робот того же градиента.

## Проверено (`node tools/smoke.js`, 180 роботов, 40 тыс. шагов)
- Без шума: «К» 94%, домик 92%, квадрат 85%, стрелка 91%; все вставшие внутри, ошибка координат 0.
- Шум 1%: домик ~93%, «К» ~60%. Шум 2%: домик ~46% — ошибка копится от слоя к слою.

## Грабли (по порядку находки)
1. Градиентный спуск для трилатерации сваливался в «зеркальные» решения (ошибка 8–55 радиусов) → линейный МНК + отказ при коллинеарности.
2. Ограничение «едут не больше 6» (не из статьи) заполнило очередь кружащими роботами → убрано.
3. Флаг «внутри» не сбрасывался — роботы вставали вне фигуры → правила остановки только пока действительно внутри.
4. Стоящие роботы непрерывно уточняли координаты друг по другу — цикл раздувал ошибки округления (×3 за 400 шагов) → один раз, с усреднением 8 замеров.
5. Затравка вне фигуры (звезда) — роботы вставали на входе и закупоривали его; узкие «карманы» между лучами заклинивали колонну →
   звезда заменена домиком, вежливая очередь (не толкать едущего впереди), выход из кармана задним ходом.
6. Едущий робот с одним шумным замером за шаг: подмешивание замера (20%) к оценке не спасло при шуме 2% — главная ошибка у стоящих слоёв.

## Открытая проблема
Сборка «К» зависит от числа роботов. После исправления взаимной блокировки (двое ждут друг друга — едет меньший номер):
90 → 88%, 110 → ~55–62%, 130 → ~55–80%, 150 → ~95%; домик, квадрат и стрелка — 87–92% уже со 110.
Факты: при застревании почти все едущие стоят в очереди за 1–2 «головами», которые не ждут, но и не продвигаются:
одна — во внешней V-впадине «К» между палочкой и верхней ногой. Расширение впадин (ноги шире) не помогло — откатили.
Вероятная причина глубже: упрощённая езда вдоль края (касательная к ближайшему соседу) плохо проходит вогнутые места.
Кандидат на исправление — езда вдоль края как в оригинале: держать одного соседа «справа» и менять его только по ходу движения.
