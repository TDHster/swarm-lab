# Абажур от слизевика

`js/lamp.js` (без DOM): слизевик (Jones 2010) на развёртке цилиндра, сетка 2 мм, по горизонтали замкнута,
сверху/снизу агенты отражаются. Плотность 0,76 агента на клетку. Затем `makeMask`: порог по квантилю «ажурности» →
расширение перемычек диском радиуса r = ⌈(мин/2 мм − 1)/2⌉ (реальный минимум (2r + 1)·2 мм: 2, 6, 10 мм) →
сплошные ободки и шов 10 мм → заливка «шахматных» углов 2 × 2 (перемычка нулевой толщины порвалась бы) → удаление
кусков, не связанных с ободками → заливка прорезей меньше заданной площади. `outlines`: обход по рёбрам клеток →
Дуглас–Пекер 0,7 клетки (лесенка → прямые) → 3 прохода Чайкина. SVG: красное — рез, синий пунктир — граница
нахлёста 10 мм.

Пресеты (угол сенсоров / дальность, клеток / поворот / выветривание, %), 200 шагов, ажурность 60%, Ø20 × 25 см, seed 1–3:

| Пресет | Прорезей | Ажурность после чистки |
|---|---|---|
| Кружево 10/5/45/30 | 50 / 51 / 61 | 55% |
| Мелкая сетка 10/3/45/30 | 61 / 62 / 63 | 55–56% |
| Крупные соты 10/7/90/30 | 32–34 | 55% |
| Прожилки 22,5/7/90/20 | 29–34 | 51–52% |

Кружево seed 1: перемычка 2 / 6 / 10 мм → ажурность 55 / 45 / 39%, прорезей 50 / 51 / 50; 500 шагов вместо 200 → 36 прорезей.

Грабли:
- Параметры со страницы `physarum/` (дальность 9–25) на маленькой развёртке за 300 шагов огрубляли сеть до 2–4 «червей»,
  висящих на ободках: пустоты сливались, абажур был бы хлипким. Замкнутую сеть дают малый угол сенсоров (10°) и сильное
  выветривание (30%) — перебор 81 комбинации, см. `tools/smoke.js`.
- Упрощение контура после сглаживания выкидывало все точки (сравнивало соседние); потом оставляло лесенки.
  Правильный порядок: сначала Дуглас–Пекер по сырой лесенке, потом Чайкин.
- Касание дырок углом давало общий контур и перемычку нулевой толщины — теперь такие углы заливаются.

`node tools/smoke.js` (~15 с): собираемость (всё связано с ободками, ободки и шов сплошные), один контур на прорезь
и площадь контуров ±2%, цифры подсказок.
