# physarum — заметки для работы

- Скрипты классические, модель без DOM; `node tools/smoke.js` — перед коммитом.
- Горячий цикл в `Mold.step()`: не вызывать там `Math.cos/sin` на сенсор и не создавать объекты.
  После правок сравнить контраст в smoke с прежним (одинаковое поведение = те же числа).
- Подсказки «Что попробовать» проверены скриншотами (README); при смене модели — перепроверить.
