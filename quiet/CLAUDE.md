# quiet — заметки для работы

- Три страницы с вкладками: `index.html` (стена), `zone.html` (тихая зона), `fans.html` (вентиляторы), общий `style.css`.
- `node tools/smoke.js` (~1 мин) — все цифры подсказок трёх страниц, перед коммитом.
- Тихая зона: устойчивость LMS зависит от числа динамиков и шага; подсказки про «разнос» проверять прогоном (README).
- Звук на всех трёх страницах (`js/sound.js`) — WebAudio, создаётся только по клику (политика автозапуска браузеров).
- Звук проверять числами на выходе: headless Chrome с `--autoplay-policy=no-user-gesture-required`, перехватить `AudioContext`, анализатор на `audio.master` (README, раздел «Звук»).
