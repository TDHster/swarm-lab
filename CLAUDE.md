# swarm-lab — учебные симуляции роевого интеллекта

Сайт: https://swarm-lab.tdhster.workers.dev/ — главная `index.html` с плитками проектов.
Сестринский проект — `../genetic` (https://genetic.tdhster.workers.dev/): то же устройство и стиль, другой цвет.

## Архитектура
- Проекты в подпапках (`boids/`, `ants/`, `physarum/`, `pso/`, `crowd/`, `stigmergy/`) независимы: общего кода нет, у каждого свои
  `index.html`, `style.css`, `js/`. **Главная цель — понятность для обучения.**
- Типовое устройство: `js/rng.js` (сид-ГСЧ), `js/model.js` (агенты и правила, без DOM), `js/draw.js`, `js/app.js`
  (UI, цикл rAF, FPS); `tools/smoke.mjs` — прогон модели в Node (на сайт не попадает).
- Страница проекта: описание → панель кнопок/ползунков (меняются на лету) → канвас с легендой →
  «Как это устроено» с SVG-схемой агента.
- Палитра: фон `#08130f`, панели `#0f1f1a`, рамки `#1f3a32`, текст `#dcefe7`, приглушённый `#86a89b`,
  акцент `#3ee6b0`, второй `#ff7ab6`. Интерфейс по-русски, комментарии в коде по-английски.
- Без библиотек и CDN (если понадобится — сначала спросить).

## Правила проверки
- Каждую подсказку и цифру на странице («Что попробовать» и т. п.) проверять прогоном модели (`tools/smoke.js`, скриншот),
  а не «по ощущению»: несколько подсказок уже оказались неверными. Цифры записывать в README проекта.
- Любое «улучшение» (эволюция, подбор параметров) — только с проверкой на свежих seed, которых оптимизация не видела:
  иначе легко принять подгонку под шум за победу (так было с колоннами в `crowd/`).
- Три неудачных подхода к одной проблеме подряд — остановиться и описать (пример — встречный поток в `crowd/README.md`).

## Локальный сервер
`python3 -m http.server 8766` в корне (порт 8765 — у genetic). Перед запуском `lsof -iTCP:8766 -sTCP:LISTEN`,
остановить — `kill <PID>`.

## Выкладывание
Cloudflare Worker `swarm-lab`, только статика. `npx wrangler deploy` сам запускает `build.command` из `wrangler.jsonc`
(`./make-site.sh` собирает `site/` через `tar`: в образе Cloudflare нет `rsync`) и выкладывает `site/`.
Автодеплой — Workers Builds по пушу в `main` (в дашборде нужна только Deploy command `npx wrangler deploy`).
Грабли: без `build.command` Workers Builds сразу делал deploy и падал — «assets.directory … site does not exist».
Статус сборки по коммиту: `gh api repos/TDHster/swarm-lab/commits/main/check-runs`.
Новый проект: плитка в `index.html` (убрать класс `soon`, обернуть в `<a href>`), строка в `README.md`.
После деплоя: `curl -s -o /dev/null -w "%{http_code}" https://swarm-lab.tdhster.workers.dev/<проект>/`.
